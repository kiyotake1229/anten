## 概要

`habit/ios-app/` と `思考力/ios-app/` を雛形に、`ios-app/` に Capacitor 7 の iOS プロジェクトを作った。手元に Xcode が無いため、GitHub Actions（macos-26・Xcode 26）で署名なしのビルドが通ることを確かめる。岩崎さんが Xcode で署名して申請するところまでの手順と申請文面を `ios-app/岩崎さんへの引き渡し手順.md` に書いた。

## 対象ファイル

- `ios-app/package.json` … `@capacitor/core` `ios` `app` `haptics` `local-notifications` `status-bar`、`sync` / `open` / `icons` スクリプト
- `ios-app/capacitor.config.json` … `appId: work.ltv.anten`、`appName: 暗転`、`webDir: www`、`contentInset: never`、StatusBar は WebView に重ねる
- `ios-app/sync-web.sh` … `../index.html` などを `www/` にコピー（`sw.js` は入れない）
- `ios-app/assets/icon.png`（1024）、`splash.png` / `splash-dark.png`（2732）… `tools/make-icons.sh` が作る。`npm run icons` でアイコンと起動画面を生成済み
- `ios-app/ios/App/App/Info.plist` … 表示名「暗転」、iPhone は縦固定、`ITSAppUsesNonExemptEncryption = NO`
- `ios-app/ios/App/App/PrivacyInfo.xcprivacy` … プライバシーマニフェスト（トラッキングなし・収集なし。UserDefaults / ファイル時刻の参照理由）。`project.pbxproj` の Resources に追加済み
- `ios-app/岩崎さんへの引き渡し手順.md` … 環境、ビルド、署名、申請情報の下書き、審査メモ、修正の反映手順
- `.github/workflows/ios-build.yml` … push ごとに npm ci → sync-web → cap sync（pod install）→ xcodebuild（Simulator Debug / 実機 Release、署名なし）→ App.app の中身を検査

## 変更内容

1. `npm install` → `bash sync-web.sh` → `npx cap add ios` でプロジェクトを生成（手元では `pod install` が Xcode 不在で失敗するが、プロジェクト自体は作られる）
2. `npm run icons` で `Assets.xcassets` にアイコンと起動画面を生成
3. `Info.plist` の向きを縦だけにし、暗号化なしを申告
4. `PrivacyInfo.xcprivacy` を作り、`project.pbxproj` に PBXBuildFile / PBXFileReference / App グループ / Resources の4か所を追加
5. `node_modules/` と `www/` は Dropbox を軽くするため消した（`npm install` と `npm run sync` で作り直せる）

## 確認

- `plutil -lint` で `Info.plist` / `PrivacyInfo.xcprivacy` / `project.pbxproj` が正しい形式であることを確認
- GitHub Actions「iOS build check」（run 38377751875、2026-10-13）: npm ci → sync-web → cap sync（pod install）→ Simulator Debug ビルド → 実機 Release ビルド → App.app の検査（index.html 同梱・sw.js なし・Bundle ID・PrivacyInfo・5つの Capacitor フレームワーク）まで**すべて成功**。https://github.com/kiyotake1229/anten/actions
