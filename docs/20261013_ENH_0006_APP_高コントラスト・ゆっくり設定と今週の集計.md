# 高コントラスト・ゆっくり設定と、今週の集計（v1.1）

- 種類: ENH（機能改善・拡張）
- 対象: 画面・保存（APP）
- 作成日: 2026-10-13

## 概要

見えにくさ・速さへの配慮として「高コントラスト」と「ゆっくり」の設定を足した。日替わりの結果に「今週 n日目 ｜ 週ベスト」と皆勤などの印を出し、共有文にも入れた。遊びの規則と列の配置は変えていない。

## 対象ファイル

- `index.html` … 設定（`DEF` / `load` / 設定シートの2行 / `refreshSettings` / クリック）、まぶたの時間 `lidK()`（`touchBegin` / `eyeOpenNow` / 薄目の移行）、残像と浮き文字の色（`drawAfter` / `drawFloaters`）、`weekKey()` / `weekSummary()`、`showResult` の日替わりの行、`shareText()`
- `tools/test.mjs` … 3件追加（ゆっくりの閉じる時間、今週の数え方、皆勤）

## 変更内容

1. **高コントラスト**（`settings.contrast`、初期 OFF）: 閉眼中の残像をシアン → 白（塗り 35% → 50%）、閉眼中の浮き文字も白。忍び列の琥珀色は変えない（「信用するな」の印として残す）
2. **ゆっくり**（`settings.slow`、初期 OFF）: まぶたの閉じる・開く・薄目の移行の時間を 1.5 倍（閉 80→120ms、開 120→180ms、薄目→閉 120→180ms）。列の速さは変えない
3. **今週の集計** `weekSummary(today)`: `dailyHistory` のうち今週（月曜はじまり）の件数と最高点。印は 3日=常連 / 5日=精勤 / 7日=皆勤。リザルト（日替わり）に「今週 n日目 ｜ 週ベスト m」、共有文の末尾に「｜今週 n日・皆勤」
4. 設定シートにアイコン2つ（`i-contrast` / `i-slow`）を追加
