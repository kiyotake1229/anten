## 概要

営業・ポートフォリオ・SNS で使い回せる1ページ `about.html` を作り、GitHub Pages で公開した（https://kiyotake1229.github.io/anten/about.html ）。最初の10秒の動画と絵コンテ、3つの決まり、スクリーンショット5枚、6つの段位の紋章、つくり（技術）、制作の進め方をまとめた。OGP を設定してあるので、URL を貼ると絵コンテが出る。

## 対象ファイル

- `about.html` … 新規。CSS・JS 込みの1ファイル。画像と動画はリポジトリ内のファイルを参照（`資料/暗転_最初の10秒.webm` と `_絵コンテ.jpg`、`ios-app/screenshots/iphone-6.9/*.jpg`）。紋章は canvas で描く（`index.html` の `drawEmblem` と同じ絵）
- `support.html` … 変更なし（フッターから相互にたどれる）
- `README.md` … URL を追記

## 構成

1. 冒頭（暗闇）: 目のアイコン、「暗転」、一言、説明、「ブラウザで遊ぶ」ボタン
2. 最初の10秒: 動画（自動再生・無音・ループ）、絵コンテ、4コマの説明
3. 見るか、動くか（紙の地。まぶたが開くように曲線でつなぐ）: 3つの決まり、読みが深まる列、スクリーンショット5枚
4. 六つの段位: 紋章と点数の範囲、熾火の色の段階
5. つくり: 1ファイル・オフライン・自動検証・公開の仕組み・制作期間
6. フッター: 遊ぶ／サポート／GitHub

スマホ幅では 1列に畳み、スクリーンショットは3枚だけ見せる。`prefers-reduced-motion` で瞬きの動きを止める。

## 確認

- ローカルの内蔵 Browser で、横幅 900px と 375px で崩れ・横スクロールがないこと、動画と画像が出ること、紋章6つが描かれることを確認
- GitHub Pages で OGP の画像 URL（日本語のパス）が開けることを確認
