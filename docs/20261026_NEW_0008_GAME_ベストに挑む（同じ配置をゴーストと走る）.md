# ベストに挑む（自己ベストと同じ配置を、ベストの軌跡と走る）

- 管理番号: #0008
- 種類: NEW（新規開発）
- 対象: ゲームの規則（GAME）と画面（APP）
- 作成日: 2026-10-26
- 関連: #0003（今日の暗転のゴースト）、#0009（同時に入れた称号の共有）

## 概要

エンドレスで自己ベストを出したときの配置（乱数の種）と軌跡を保存し、リザルトの「ベストに挑む」から同じ配置にもう一度挑めるようにした。走っている間は「ベスト」と書いた輪（ゴースト）がそのときの軌跡をなぞる。エンドレス自体は従来どおり毎回ちがう配置。

## 対象ファイル

- `index.html` … 保存（`DEF` の `bestSeed` / `bestGhost` / `bestDark`、`load` の検証）、`G.seed`、`toReady()` のモード分岐（`endless` / `best` / `daily`）、`step()` の軌跡の記録（全モード）、`showResult()`（ベスト更新時に種と軌跡を保存）、`ghostData()` / `drawGhost()`、`resultButtons()`、HUD の表示（`updateDom`）、リザルトのボタン（`#rBest` / `#rEndless`）
- `tools/test.mjs` … 9件追加（[7] ベストに挑むと称号の画像）

## 変更内容

1. **保存**: `S.bestSeed`（ベストを出した配置の種）、`S.bestGhost`（30回/秒の x の軌跡。最大8,000点）、`S.bestDark`（ベストの暗列数）。読み込み時に検証し、壊れていれば捨てる
2. **軌跡の記録**: これまで日替わりだけだった `G.trace` の記録を全モードに広げた（ベストを更新したときに `bestGhost` として残すため）
3. **モード `best`**: `toReady()` で `G.seed = S.bestSeed` の配置を作る。HUD は「ベストに挑戦 57」。ゴーストは `ghostData()` がモードに応じて `daily.ghost` か `bestGhost` を返す。ベストを超えた瞬間にトースト「ベストを超えた」。このモードの得点も通常どおりベスト・累計に数える（ベストを更新すれば、その走りが次のゴーストになる。配置は同じまま）
4. **リザルトのボタン**（`resultButtons()`）: エンドレス＝設定・今日の暗転・称号を共有・ベストに挑む（ベストがあるとき）／ ベストに挑戦中＝設定・称号を共有・エンドレスへ／ 日替わり＝設定・エンドレスへ（3回終わったら共有も）。アイコンの下に小さな文字を付けた
5. 「エンドレスへ」で新しい種のエンドレスに戻る
