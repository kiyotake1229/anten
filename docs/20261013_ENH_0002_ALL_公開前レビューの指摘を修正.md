## 変更内容

### 1. 不具合の修正（遊んでいて目に見えるもの）

| 指摘 | 直し方 |
|---|---|
| エンドレスではモード表示が空（`display:none`）になり、HUD の格子が詰まってスコアが左寄り・一時停止ボタンが中央に出ていた | `#mode` / `.mid` / `#pauseBtn` に `grid-column` を固定 |
| タッチの `pointerdown` はブラウザの「ユーザー操作」に数えられず、Android / iPhone で最初のタッチが無音になり、2回目にまとめて鳴る | `pointerup` でも `audioInit()`（resume）を呼ぶ。`tone()` / `noise()` は AudioContext が `running` のときだけ音を予約する |
| 画面が大きくなる方向のリサイズ（横→縦、Artifact の枠を広げる）で、まぶたの位置が古い高さのまま残り、画面の下に黒い帯が出続ける | `layout()` でまぶたの6つの値を新しい高さに移し替える |
| リザルトが出た瞬間のタップで次のラウンドが始まり、結果を見ずに真っ暗で始まることがある | 出てから 0.4 秒はタップを無視。READY に入って 0.15 秒も無視（連打の2回目を吸収） |
| 一時停止の直後、まぶたが開きかけのまま画面が固まって見える（描画の節約が早すぎた） | まぶたが開き切るまで描き続けてから止める |
| 一時停止中に忍び列の擦れる音が残り、再開後 0.5 秒鳴る | `pause()` で擦れる音を止める。音の側も PLAY 中以外は鳴らさない |
| 熾火の解放演出が 0.4 秒遅れで出るため、連打で次のラウンドに入ってから鳴ることがあった | RESULT のままのときだけ出す。熾火を描く条件も時間で区切る |
| 日替わりで日付をまたぐと、始めた日ではなく新しい日の記録になり、回数も戻っていた | リザルトで日付を見直さない。挑戦の回数は始めた時点で数える（途中で閉じても同じ配置をやり直せない） |
| 「データを消す」のあと音量が元に戻らない（音 OFF のまま） | 消したあとに `setMaster()` |
| Android で `pointercancel` の座標が (0,0) になり「指が外れた」のリングが左上に出る | 最後に触れていた位置を覚えておいて使う |
| `pointerup` を取りこぼすと以後のタッチを全部無視してしまう | 新しい主ポインタが来たら前の指を離した扱いにして続ける |
| 手動の一時停止で AudioContext を止めていたため、停止ボタン自身の音が飲み込まれ、再開時にまとめて鳴る | 一時停止では止めない（非表示のときだけ止める） |
| 死亡の瞬間にまぶたが閉じる途中だと、死んだあとにハム音が立ち上がる | ハムは PLAY 中だけ鳴らす |
| 保存データの `tier` が範囲外だと起動直後に毎フレーム例外で止まる | 読み込み時に数値を正規化し、`tier` は累計から求め直す |

### 2. 性能

- canvas を `alpha:false` で作る。全画面の塗りを1回に減らす（論理座標側の塗りを削除）
- 霧のグラデーション（本体1本・帯2本×2段階）を `layout()` で作って使い回す
- 忍び列の擦れる音の `setTargetAtTime` を、状態が変わったときだけ発行（毎物理ステップ → 変化時）
- 一時停止中は描画を止める（まぶたが開き切ったあと）
- 虹の熾火の色相を 6° 刻みにして、放射グラデーションの作り直しを減らす
- フォント指定の文字列を定数にする（毎フレームの連結をやめる）
- `resize` / `visualViewport.resize` は大きさが変わったときだけ `layout()` する（iOS のツールバーの出入りで一時停止しない）
- DPR の上限を 2 → 3 にし、総ピクセル数（450万）で頭打ちにする（iPhone で線と文字がにじまない）

### 3. デザイン・文言

- 閉眼中もスコア・ベストの金色が消えないように（`body.dark` の詳細度）。HUD の色の切り替えを 0.25 秒 → 0.06 秒（まぶたの速さに合わせる）
- 列は霧の中（`FY − 70`）に現れ、降りながら見えてくる（以前は出現線でほぼ実体のまま出ていた）
- 開眼時の熾火に墨色の輪郭と薄い影を付け、紙の上で見失わないようにする
- 暗列の浮き文字は、紙の上では濃い水色（`#1098B8`）にして読めるようにする。ヒヤリの火花は閉眼中はシアン
- READY で「触れて開始」を点滅表示（リザルト後の1タップ目で何も起きないように見えていた）
- 「離すと見える」のヒントは本当に初回3ラウンドだけ（以前は毎回3ラウンド出ていた）
- 開眼時の霧の一瞬の濃さ（`fogPulse`）が一度も動いていなかったのを直す
- 暗列で閉眼リングが明るくなる時間を 0.25 秒 → 1 秒（1周ぶん）
- 忍び列の初出ラベルが画面端で切れないように位置を調整
- まぶたが横長画面の余白まで覆うように。HUD の幅を 600px までに制限
- 閉眼中のトーストを紙色に。タイトル文字の後ろに紙色のぼかしを敷き、黒い列と重なっても読める
- リザルトのシートを少し詰めて、死亡地点が見える範囲を広げる。熾火が虹のときの進捗バーが 0% になっていたのを 100% に
- 設定のスイッチとボタンのタップ領域を 44px に広げ、行のどこを押しても切り替わるように。リザルト・設定のシートは閉じているとき `visibility:hidden`（キーボードで裏から押せない）
- `theme-color` を閉眼中は黒に切り替える。Artifact の外側に包まれても `lang="ja"` を保つ
- 文言: 「消しました」→「消した」、「蒼まで」→「蒼の熾火まで」、設定の説明に「熾火（おきび）＝自分」を追加
- 死亡のひびを短く細く（最大 120px、1.5px）

### 4. 検証用の仕組み

- `__anten.simulate()` が実ゲームの状態（ヒットストップ・演出・DOM のフラグ・生成ログ）を汚さないよう、触るものをすべて保存して戻す
- `__anten.advance(秒)` を追加（画面が止まっていても内部時間を進める。レビュー中のブラウザが毎秒2コマしか描けない環境でも流れを確認できる）
