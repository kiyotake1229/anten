## 概要

タイトルの「記録」から、端末内の上位10回（得点・列数・暗列・連続・日付・モード）と累計（回数・列・暗列・最長連続暗）を見られるシートを足した。遊びの規則は変えていない。難易度設定は付けない方針（理由は README「設計の線引き」）。

## 対象ファイル

- `index.html` … 保存 `S.records`（最大10件。`load` で検証・切り詰め）、`showResult()` で追加と並べ替え、`openRecords()` / `closeRecords()`、`#records` シート（`#settings` と同じ見た目）、タイトルの `#tRecords` ボタン、アイコン `i-rec`、scrim / Esc の閉じる順序
- `tools/test.mjs` … 3件追加（切り詰め、並び、シートの中身）

## 変更内容

1. `S.records` に `{ s: 得点, r: 列, d: 暗列, k: 最長連続暗, date, m: 'e'|'d'|'b' }` を保存。得点順（同点は新しい方が上）で10件
2. シート: 上に累計4つ（回 / 累計の列 / 暗列 / 最長連続暗）、下に順位つきの一覧。1位は金色。空なら「まだ記録がない」
3. タイトルのボタンを 設定 / 今日の暗転 / 記録 / 音 の4つに
