## 仕様

### 1. 用語

| 用語 | 意味 | コード上の名前 |
|---|---|---|
| 列 | 上から落ちてくる黒い横帯。必ず隙間が1つ | `rows[]` の要素 |
| 隙間 | 列の中で通れる部分 | `gapX`（中心）`gapW`（幅） |
| 熾火（おきび） | 自機。白く光る点 | `player` |
| 開眼 / 閉眼 / 薄目 | まぶたの状態 | `eye.mode` = `OPEN` / `CLOSED` / `SQUINT`（と各移行中） |
| 残像 | 閉眼した瞬間に見えていた列の静止コピー | `after.rows` |
| 据え列 / 移り列 | 前の隙間と重なる列 / 動かないと抜けられない列 | `kind` = `STAY` / `MOVE` |
| 忍び列 | 閉眼している間だけ横に動く列 | `shinobi: true, drift` |
| 暗列 | 閉じたまま抜けた列（加点） | `onPass()` の `dark` |

### 2. 座標と画面

- 論理幅 `W = 360`。論理高さ `LH = clamp(round(360 × 画面の高さ / 幅), 560, 820)`。`SC = min(幅/360, 高さ/LH)` で縮尺し中央に置く（余白は背景色）
- 自機の高さ `PY = round(LH × 0.62)`。霧の線（列が現れる高さ）`FY = PY − 300`。どの端末でも「見える助走」は300px
- 列の厚み `RH = 22`、角丸3px。自機の当たり半径 `PR = 10`（見た目は半径12、光輪28）
- `devicePixelRatio` は最大3まで（総ピクセル数 450万で頭打ち）。描画は毎フレーム `setTransform` で論理座標に合わせる

### 3. 操作（Pointer Events。touch / mouse / pen 共通）

- **pointerdown**: 最初の1本だけ追跡（`pointer.id`）。2本目以降は無視。タイトル・READY なら開始。前回離してから **0.25秒以上**なら閉眼（残像を取ってまぶたを80msで閉じる）、**0.25秒未満**なら薄目（80msで帯の形に閉じ、0.4秒たつと閉眼に移る）
- **pointermove**: 横の移動量 × 感度（タッチ 1.2 / 1.6 / 2.0、マウス 1.0）を自機の目標 `tx` に足す。指の縦位置は無視（相対ドラッグ。親指で画面が隠れない）
- **pointerup / pointercancel / lostpointercapture / blur / 非表示**: すべて `release()`。まぶたを120msで開き、自機は止まる（`tx = x`）。暗連続は0に戻る。`pointercancel` のときは灰色のリングと「指が外れた」を出し、1ラウンドで2回なら案内を1回出す
- 自機は毎物理ステップで `x += (tx − x) × (1 − e^(−dt/0.05))`、1ステップの移動は `PMAX = 900 px/s` で上限
- キーボード（開発用）: `Space` 押下中 = 触っている扱い、`←` `→` で 600px/s、`B` 自動操縦、`G` 生成ログ、`P` / `Esc` 一時停止

### 4. 生成（難易度の式）。乱数は `gen.rng`（mulberry32）だけを使う

| 量 | 式（k = 通過した列数） |
|---|---|
| 速度 `v` | `min(360, 140 + 5k)` px/s（k=44 で上限） |
| 列の間隔 `S` | 150 px（一定） |
| 隙間の幅 `G` | k<5: 170 / 以後 `clamp(120 − 0.8(k−5), 72, 120)`（k=65 で72） |
| 隙間の中心の範囲 | `[G/2 + 20, 360 − G/2 − 20]`（左右のブロックは必ず20px以上残る） |
| 移り列の最大距離 `DMAX` | `clamp(0.55 × 900 × ((S − 22 − 20)/v − 0.12), 60, 220)`。前の列を抜けてから次の列に入るまでの時間から反応の120msを引き、最高速の55%で届く距離。k=0: 220 / k=20: 163 / k=44以降: 89 |
| 据え列の確率 | k<10: 0.5 / 以後 `max(0.25, 0.5 − (k−10) × 0.25/30)` |

- **据え列**: 前の中心から `±clamp(G/2 − 24, 8, 24)` 以内（幅120で±24、幅72で±12）
- **移り列**: 前の中心から `G/2 + 4` 以上 `DMAX` 以下離す（前の中心に居ると必ずブロックに当たる）。方向は乱数だが、中心が100未満なら右へ80%、260超なら左へ80%。片側に余地が無ければ反対へ。どちらも無理なら据え列にする
- **強制規則**: 移り列が2本続いたら次は必ず据え列（`gen.moveRun`）
- **チュートリアル列（k=0〜4、固定）**: 幅170、中心 `180, 200, 90, 110, 240`、種別 `据・据・移・据・移`
- **忍び列**: k≥12 の移り列で、移りの1本目（`moveRun = 0`）のとき、確率 `min(0.35, 0.15 + 0.005(k−12))`。速さ `30 + min(40, k−12)` px/s。出現時の中心 `c0` と、ずっと閉眼していた場合の到達位置 `c0 + drift × (370/v)` の両方が範囲内かつ前の中心から `DMAX` 以内のときだけ付ける（だめなら向きを反転、それでもだめなら付けない）。忍び列の次は「忍びの取りうる範囲のどこからでも届く位置」の移り列、その次は強制据え列（`gen.afterShinobi` 2→1→0）。忍び列は2本続かない
- 列は霧の中 `FY − 70`（`spawnY()`）に現れ（直前の列がそこから `S` 進んだとき）、降りながら霧を抜けて見えてくる。`LH + 20` を過ぎたら捨てる。READY のときは `FY + 150` と `FY` に2本置いて止めておく
- エンドレスの種は `Date.now() ^ 乱数`、今日の暗転は `hashStr('anten:' + 'YYYY-MM-DD')`（端末のローカル日付）

### 5. 物理（固定ステップ 1/120 秒。1フレーム最大6ステップ）

- 列は `v × dt` 下がる。閉眼（`CLOSED`）中だけ忍び列の `gapX += drift × dt`。範囲の端に当たったら `drift = 0`
- 当たり判定: 自機の円（半径10） vs ブロックの矩形（隙間側の縁と上下を2px内側に縮めたもの）。`|row.y − PY| < 11 + 10 + 4` の列だけ調べる
- 通過: `row.y − 11 > PY + 10` を初めて満たしたステップで `onPass()`
- 通過中の「縁までの余裕」の最小値 `minGap` を記録し、6px以下なら **ヒヤリ**（60msだけ0.4倍速、火花、音、振動）
- 時計は2つ: `gameTime`（ヒットストップ・スローで倍率がかかる）と `fxTime`（常に実時間。まぶた・粒子・浮き文字・タイマー `later()`）。フレーム間隔は50msで上限

### 6. 得点

- 暗列 = 通過の瞬間に `eye.mode === 'CLOSED'` かつ `eye.closedSince <= 前の通過時刻` かつ `k >= 1`。つまり「前の列を抜ける前から閉じっぱなし」。50msだけ触る「タップ抜け」は暗列にならない
- 暗列: `streak += 1`、得点 `min(1 + streak, 5)`（+2, +3, +4, +5, +5…）。それ以外は +1 で `streak = 0`。指を離した時点でも `streak = 0`
- 近さによる加点はない（ヒヤリは演出だけ）

### 7. まぶた（状態機械。`fxTime` で動く）

| 遷移 | 時間 | 補足 |
|---|---|---|
| OPEN → CLOSING → CLOSED | 80ms（easeInQuad） | 閉じ切った時刻を `closedSince` に。ハム音が300msでフェードイン |
| 任意 → OPENING → OPEN | 120ms（easeOutCubic、今の位置から） | OPEN 到達で残像を捨てる |
| OPEN → SQUINT_IN → SQUINT | 80ms | 上まぶたの縁 `PY − 90`、下 `PY + 70`。帯の中の列は灰色、格子は描かない |
| SQUINT → SQUINT_TO_CLOSED → CLOSED | 120ms（pointerdown から 0.4秒で開始） | 薄目で見えていた帯の列だけ残像にする |
| 死亡 | ヒットストップ150ms → 60msで強制開眼 | |

- 残像は閉じた瞬間の列のコピー（静止）。透明度 `(1 − t/T)²`、`T = clamp(1.0 − 0.008(k − 10), 0.6, 1.0)` 秒。忍び列は琥珀色、それ以外はシアン
- 開眼時の白フラッシュは入れない（点滅対策）。連打は薄目になるので画面が点滅しない

### 8. 進行と画面

- 状態: `TITLE / READY / PLAY / DEAD / RESULT / PAUSED`（`ST`）
- タイトル: 「暗転」「触ると動ける。でも見えない」「画面のどこを触ってもいい」（累計3回まで）。下に 設定 / 今日の暗転 / 音 のボタンと「ベスト ｜ 累計」。画面のどこを触っても開始（ボタン上は除く）
- プレイ: 上中央にスコア（加点でポップ、ベスト超えで金色）とベスト。左上にモード（今日の暗転なら「今日 n/3」）。右上に一時停止
- 死亡 → 150ms止める → まぶたを開く → 熾火が24粒に砕ける → 画面揺れ8px/300ms → 衝突点から5本のひび → 殺した列が赤で3回点滅 → 0.5秒後にリザルトのシートが下から出る
- リザルト: スコア、「ベスト更新」、段位、列数 / 暗列 / 最長連続暗、次の熾火までの進捗バー、「タップでもう一回」、設定 / 今日の暗転（または 共有 / エンドレスへ）。シートのどこを触っても READY に戻り（次の2列が止まって見える）、次のタッチで開始。最短0.5秒・タップ2回
- 一時停止: 「一時停止 / タップで再開」。再開後0.5秒は列を止めたまま。非表示・blur・リサイズでも一時停止
- 設定（シート）: 音、振動、感度（低 1.2 / 標準 1.6 / 高 2.0）、操作の説明、データを消す（2回押し。3秒以内）、v1.0

### 9. 持続要素と保存（localStorage キー `anten.v1`、JSON 1個）

```json
{ "v": 1, "best": 0, "bestRows": 0, "bestDate": "", "maxDarkStreak": 0,
  "totalRows": 0, "totalDarkRows": 0, "totalPlays": 0, "tier": 0,
  "daily": { "date": "", "tries": 0, "best": 0, "bestRows": 0, "bestDark": 0 },
  "dailyHistory": [ { "date": "2026-10-12", "best": 54 } ],
  "settings": { "sound": true, "vibe": true, "gain": 1.6 },
  "hints": { "firstTouch": 0, "dark": 0, "squint": 0, "shinobi": 0, "cancel": 0 } }
```

- 読み書きは `try/catch`。失敗したらメモリ上で動き、画面には何も出さない。`JSON.parse` 失敗や `v` 不一致は初期値。欠けた項目は補い、感度が 1.2/1.6/2 以外なら 1.6 に戻す
- 書き込みはラウンド終了時・設定を閉じたとき・データ消去時
- 段位（自己ベスト）: 見習い 0〜 / 手探り 20〜 / 夜目 50〜 / 暗中 100〜 / 心眼 200〜 / 無明 400〜
- 熾火の色（累計列数）: 白 0 / 蒼 100 / 金 400 / 紅 1,200 / 虹 3,000（色相が4秒で1周）。解放はリザルトで色が1秒かけて変わり、リングが広がり、4音のアルペジオ
- 今日の暗転: 日付でシードが決まる。1日3回。3回使い切ると「今日の記録 n点 ／ 明日また」と共有（`navigator.share` → クリップボード → 選択済みの欄、の順）。共有文: `暗転 2026/10/12｜87点（32列・暗14）｜段位 夜目`。挑戦中に日付が変わっても始めた日の記録
- ヒント（回数を保存）: 初回3ラウンドはまぶたの裏に「離すと見える」、初めての暗列・薄目・指外れ2回にトースト、忍び列は初出3回にラベル

### 10. 演出・音・触覚

- 開眼側: 紙色の背景に40px格子が速度 `v` で流れる。列は墨色、隙間の中心に1×6pxの目印。忍び列は紙色の山形（速さ50未満で1つ、以上で2つ）。霧は `FY−60〜FY+24` の縦グラデーション＋ゆっくり上下する帯2本。速度300以上で細い速度線6本
- 閉眼側: 漆黒＋ビネット、残像、`PY` の合わせ目の線、熾火（光量70%）、閉眼リング（1秒で1周。暗列で一瞬明るく）、浮き文字はシアン
- まぶた: 上下から黒い帯（縁は中央が12px下がる二次曲線、縁に1pxのハイライト）。動作中は世界の上に重ね、熾火と残像は閉じ具合に比例した透明度で上に描く。HUD の色は閉じ具合が半分を超えたら `body.dark` で切り替える
- 熾火: 放射グラデーション（白→色→透明）、直近8フレームの尾、暗連続3以上で火花4粒が周回、暗連続中は右上に「暗×n」
- 音（WebAudio のみ。最初の pointerdown で `AudioContext` を作る。`master → DynamicsCompressor → destination`。同時発音8まで）: 閉眼（sine 90→60Hz + ノイズ）、閉眼中のハム（55+110Hz）、開眼（ノイズ + 段階ごとの上昇音 440/494/554/659/784Hz）、通過（square 1200Hz 20ms）、暗列（バンドパスノイズ。中心周波数は隙間の幅、左右の定位は隙間の位置。太鼓は連続数で上がる）、忍び列の擦れる音（動いている間）、ヒヤリ、死亡（ノイズのスイープ + ガラス音）、リザルト、解放、ボタン
- 触覚 `haptic()`: 閉眼 5 / 暗列 8 / ヒヤリ 12 / 死亡 60 / ベスト更新 [20,40,20] / 解放 [10,30,10,30,30] / 日替わり3回終了 [15,30,15]。Capacitor のときは Haptics（この関数だけ差し替える）
- `prefers-reduced-motion` では画面揺れ・スロー・速度線を止める（まぶたはゲームそのものなので残す）

### 11. 公平性の保証と検証

1. 隙間は必ず1つ、幅72px以上
2. 移り列の距離は `DMAX` 以内（反応120ms後に最高速の55%で届く）
3. 移り列は2本まで。3本目は必ず据え列（見える2列の先に必ず「止まって見ていられる列」がある）
4. 忍び列は移り列限定、連続しない、可動範囲の両端から次の列へ届く
5. 最初の5列はチュートリアル配置。世界はタイトル/READY で止まっている
6. 自動操縦ボット（`__anten.simulate`）: A「目を気にせず、通過の120ms後から次の隙間の中心へ540px/s」が40シード×500列、B「常に閉眼（忍び列が最大限に動く）で予測位置を狙う」が40シード×400列を無死で抜けることを `tools/test.mjs` で確かめる

### 12. 環境差への対応

- Claude Artifact: `fetch` / `blob:` / 外部画像 / 外部フォントを使わない。`localStorage` と `navigator.vibrate` / `share` / `clipboard` は `try/catch`。Service Worker は `https` かつ `claude` を含まないホストでだけ登録（localhost でも登録しない）
- iOS: `touch-action: none`、`user-select: none`、`contextmenu` / `gesturestart` / `dblclick` を抑止、`viewport-fit=cover` と `env(safe-area-inset-*)`
- 画面回転・リサイズ: 100msのデバウンスで、大きさが変わったときだけ `layout()`。列の y とまぶたの位置は `PY` からの相対距離を保つ。プレイ中なら一時停止
- 短い画面（LH < 560）や横長・PC は中央に収めて余白を背景色で塗る
