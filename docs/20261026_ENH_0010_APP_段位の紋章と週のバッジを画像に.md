# 段位の紋章と、週のバッジを称号の画像に

- 管理番号: #0010
- 種類: ENH（機能改善・拡張）
- 対象: 画面（APP）
- 作成日: 2026-10-26
- 関連: #0009（称号の画像）、#0006（週の集計）、#0011（紹介ページでも同じ紋章を使う）

## 概要

6つの段位にそれぞれ紋章（絵柄）を付け、称号の共有画像とリザルトの「段位」の横に出すようにした。日替わりの共有画像には、週のバッジ（常連・精勤・皆勤）があるとき金色の帯と月桂の弧を描く。文字だけだった称号に見た目の差がつき、SNS で見分けがつく。

## 対象ファイル

- `index.html` … `rankIndex()`、`drawEmblem(g, cx, cy, r, idx, emberCol, dark)`、`makeShareImage()`（紋章と週バッジ、文字の配置を調整）、`shareInfo()`（日替わりに `week` を追加）、`drawResultEmblem()`（リザルトの `#rEmblem`）
- `about.html` … 同じ紋章を描く（#0011）

## 紋章の意味

| 段位 | 絵柄 |
|---|---|
| 見習い（0〜） | 小さな熾火と細い輪 |
| 手探り（20〜） | 熾火の左右に点線の弧（手探りの軌跡） |
| 夜目（50〜） | 半分閉じた目（アプリのアイコンと同じ） |
| 暗中（100〜） | 熾火を囲む4本の残像 |
| 心眼（200〜） | 開いた目と8本の光 |
| 無明（400〜） | 二重の輪の中で光る熾火（闇そのものが光る） |

暗い地（共有画像）では紙色の線・シアンの差し色・熾火の色の光、紙の地（リザルト）では墨の線・濃い水色で描く。

## 変更内容

1. `drawEmblem()` を1つ書き、共有画像（半径150）とリザルト（56px の canvas、36px 表示）で共用
2. 共有画像の配置: 紋章 y=440 → ラベル 650 → 段位 790 → 得点 960 → 統計 1060 → 週バッジ 1135（あるとき）→ 日付 → URL 1270
3. 週バッジ: `info.week.badge` があれば「今週 n日 ・ 皆勤」を金色で描き、左右に月桂の弧と葉
4. リザルトの `#rRank` を flex にして紋章を左に置く
