# App Store 用スクリーンショットと、営業用の動画「最初の10秒」

- 管理番号: #0007
- 種類: DOC（ドキュメント・素材作成）
- 対象: iOS アプリ（IOS）と社内資料
- 作成日: 2026-10-13
- 関連: #0005（引き渡し）、#0003（v1.1 の画面）

## 概要

岩崎さんが申請するときに必要な App Store 用スクリーンショット（4サイズ×5枚、見出し入り）を、画面なしの Chrome で自動生成した。あわせて、営業・ポートフォリオ用に「最初の10秒」の動画（APNG と WebM）と4コマの絵コンテを `資料/` に作った。

## 対象ファイル

- `tools/screenshot-frame.html` … 台紙。見出し・副題、端末の枠、場面ごとの操作（`SCENES`）。アプリを iframe で開き、実時間の描画ループを止めて `__anten.advance()` で内部時間だけを進める
- `tools/make-screenshots.mjs` … 凪の池の仕組みを流用。小さな Web サーバー → Chrome（headless）→ DevTools Protocol で撮影。出力 `ios-app/screenshots/<端末>/<番号>-<場面>.jpg`
- `tools/make-promo.mjs` … 「人のような指」（移り列が見えたら触れて動き、2列抜けたら離す。離してから 0.4 秒は触らない）を合成し、1/15 秒ごとに 165 コマ撮って APNG に組む。WebM は Chrome の MediaRecorder でコマを実時間再生しながら録画。絵コンテは 1.0 / 1.9 / 2.6 / 4.2 秒のコマ
- `ios-app/screenshots/` … iphone-6.9（1320×2868）/ iphone-6.5（1284×2778）/ iphone-5.5（1242×2208）/ ipad-13（2064×2752）、各5枚
- `資料/暗転_最初の10秒.png`（APNG、約 8.5MB）/ `資料/暗転_最初の10秒.webm`（約 1.1MB）/ `資料/暗転_最初の10秒_絵コンテ.jpg`
- `ios-app/岩崎さんへの引き渡し手順.md` … スクリーンショットの章を更新

## 場面と見出し

| # | 場面 | 見出し |
|---|---|---|
| 1 | タイトル | 触ると動ける。でも見えない ／ 見るか動くかを、親指ひとつで |
| 2 | 開眼中（9列目） | 離すと見える。でも動けない ／ 隙間を読んで、また閉じる |
| 3 | 閉眼中（残像とヒント） | 閉じたまま抜けると +2 +3 +4 +5 ／ 残像と音だけが頼り |
| 4 | リザルト（41点・手探り・ベスト更新） | 段位が上がり、熾火の色が変わる ／ タップ2回で、もう一回 |
| 5 | 今日の暗転（2回目、ゴーストの輪） | 今日の暗転は、1日3回だけ ／ 自己ベストの軌跡と走る |

## つまずいた点（次に作り直すとき用）

- 画面なしの Chrome でもゲームは実時間で進むので、撮影の待ち時間（タイトルが消える CSS の 0.35 秒）の間に自機が死ぬことがあった → `requestAnimationFrame` を空にして止め、`advance()` だけで進める
- リザルトが出た直後 0.4 秒はタップを無視する決まり（#0002）があるので、台紙の `tapResult()` は 0.6 秒進めてから押す
- 指を離してすぐ触ると「薄目」になる（0.25 秒の決まり）。動画の指は離してから 0.4 秒空ける
- 操作の途中で出たトーストは実時間で消えるため、撮る前に `#toasts` を空にする

## 作り直し方

```bash
node tools/make-screenshots.mjs   # 約5分。ios-app/screenshots/ を上書き
node tools/make-promo.mjs         # 約2分。資料/ を上書き
```
