# 選択列・鏡の列・今日の暗転のゴースト、ネイティブ連携（v1.1）

- 管理番号: #0003
- 種類: NEW（新規開発）
- 対象: ゲームの規則（GAME）と画面（APP）
- 作成日: 2026-10-13
- 関連: #0001（現状の仕様）、#0005（iOS プロジェクト。ここで足したネイティブ連携を使う）

## 概要

v1.0 の拡張案のうち「隙間が2つの列」「閉眼中だけ左右が反転する列」「自己ベストのゴースト」を実装し、v1.1 とした。あわせて iOS アプリ化に備えて、ローカル通知（朝のお知らせ）とステータスバーの切り替えをアプリ内に入れた（ブラウザでは何もしない）。**列の作り方が変わるので、同じ日付の「今日の暗転」の配置は v1.0 と変わる**（30列目以降。チュートリアルと序盤は同じ）。

## 対象ファイル

- `index.html` … 生成（`nextSpec` / `addRow`）、物理（`blockDist` / `collides` / `step`）、入力（`touchMove`）、描画（`blockPaths` / `mirrorMark` / `drawGhost` / `drawDark`）、保存（`DEF` / `load` / `checkDailyDate` / `showResult`）、ネイティブ連携の節（`notifyApply` / `statusBarDark`）、設定シート（朝のお知らせの行）
- `tools/test.mjs` … 5件追加（選択列・鏡の列が出ること、鏡が3本1組で忍び・選択と重ならないこと、鏡で入力が反転すること、ゴーストの保存、挑戦回数の数え方）
- `support.html` … 遊び方に列の種類を追記

## 変更内容

### 1. 選択列（隙間が2つの列）

- 30列目以降、忍び列でも忍びの直後でも鏡でもない列に 25% で付く
- 本物の隙間 `gapX` は従来の規則（据え/移り・DMAX）で決まる。もう1つの隙間 `gap2X` は本物から `幅 + 24px` 以上離れた所に置く（左右のうち置ける側から乱数で選ぶ。置けなければ付けない）
- 次の列は本物の隙間から決まるので、`gap2X` を通ると次の隙間が遠く、間に合わないことが多い（高速では DMAX を超える）。「必ず通れる道がある」保証は本物の隙間で保たれる
- 当たり判定はブロックを3つ（左・真ん中・右）にして `blockDist()` で最寄りのブロックまでの距離を取る。ヒヤリ判定は2つの隙間のうち広い方で見る
- 残像にも2つ目の隙間を写す。隙間の目印は両方に描く（どちらが本物かは画面では分からない）
- 初出3回はラベル「選択：片方は次につながらない」

### 2. 鏡の列（閉眼中だけ左右が逆）

- 40列目以降、忍びでも忍びの直後でもない列から 1/10 で始まり、3本続く（`gen.mirrorLeft`）。終わったら12列は出さない（`gen.mirrorCool`）。鏡の区間には忍び列も選択列も出さない
- 次に抜ける列（`nextRow()`）が鏡のとき、`touchMove()` の横移動を反転する（キーボードも同じ）。目を開けているときは動けないので、結果として「閉じている間だけ逆」になる
- 隙間の中に「鏡」の文字を描く（開眼時は墨色、残像ではシアン）。閉眼中は熾火の左上に「鏡 ⇄」を出す
- 初出3回はラベル「鏡：閉じている間は左右が逆」
- 自動検証ボットは `tx` を直接動かすので影響を受けない（公平性の保証は変わらない）

### 3. 今日の暗転のゴースト

- 日替わりのプレイ中、物理ステップ4回ごと（30回/秒）に熾火の x を `G.trace` に記録する（最大8,000点）
- リザルトで、その日のベストを更新したとき（または初回）に `S.daily.ghost` に軌跡、`S.daily.ghostScore` に得点を保存する。日付が変わると消える
- 2回目以降のプレイでは `gameTime × 30` 番目の x に「ベスト」と書いた輪を描く（開眼時は灰色、閉眼時はシアンで薄く）。ゴーストの得点を超えた瞬間にトースト「今日のベストを超えた」
- 列の動きは時間だけで決まり、ヒヤリのスローは `gameTime` を遅くするので、軌跡は同じ時間軸で重なる

### 4. ネイティブ連携（iOS アプリのときだけ動く。`NATIVE` が偽なら何もしない）

- `notifyApply(fromToggle)`: 毎朝8時の通知を14日ぶん予約する（id 100〜113）。起動時と設定の切り替え時に、いったん全部消してから予約し直す。許可されていなければ設定を OFF に戻す
- `statusBarDark(dark)`: まぶたが半分以上閉じたらステータスバーを明るい文字に、開いたら暗い文字に
- 設定シートに「朝のお知らせ」の行を足した（アプリ版で `LocalNotifications` があるときだけ表示）。保存は `settings.notify`（初期 OFF）
- 触覚は従来の `haptic()` のまま（Capacitor の Haptics に自動で切り替わる）

### 5. そのほか

- 版を 1.1 に。設定の「操作の説明」に忍び列・鏡・選択列の1行を追加
