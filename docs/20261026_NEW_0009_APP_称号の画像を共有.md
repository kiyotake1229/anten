## 概要

リザルトの「称号を共有」で、段位・得点・列数・暗列・日付を暗闇と残像の絵柄で1枚の画像（1080×1350）にして共有できるようにした。ブラウザは Web Share（画像つき）→ 画像を見せて長押し保存、の順。iOS アプリは Capacitor の Filesystem と Share で共有シートを出す（写真への保存も可）。日替わりの「共有」も同じ画像つきになった。

## 対象ファイル

- `index.html` … `makeShareImage(info)`（canvas で描く）、`shareInfo()`（文面と数字）、`shareRank()`（iOS → Web Share → 画像シートの順）、`#shareSheet`（画像・長押しの案内・文面をコピー・閉じる）、`openShareSheet` / `closeShareSheet`（開いている間はゲームの入力を止める。scrim と Esc で閉じる）
- `ios-app/package.json` / `package-lock.json` … `@capacitor/share` `@capacitor/filesystem` を追加（`npm install` で lock を更新し、`node_modules` は消した）
- `ios-app/ios/App/App/Info.plist` … `NSPhotoLibraryAddUsageDescription`（共有シートの「画像を保存」で必要）
- `.github/workflows/ios-build.yml` … フレームワークの検査に CapacitorShare / CapacitorFilesystem、Info.plist の検査に上のキーを追加
- `ios-app/岩崎さんへの引き渡し手順.md` … ネイティブ機能・審査メモ・Info.plist の説明を更新

## 画像の構成（1080×1350）

| 位置 | 内容 |
|---|---|
| 上 | 「暗転」「触ると動ける。でも見えない」（シアン）。まぶたの縁の曲線 |
| 中 | 残像の列3本（シアン、薄く）、熾火の光（その人の熾火の色）。ラベル（「段位」または「今日の暗転 日付」）、段位 210px、得点 128px + 点 |
| 下 | 「n列 ・ 暗列 n ・ 最長連続暗 n」、日付、URL |

## 共有の順番

1. iOS アプリ（`NATIVE` かつ `CAP.Share` と `CAP.Filesystem`）: PNG を `CACHE` に書き、`Share.share({ text, files })`。キャンセルは静かに終わる
2. ブラウザで `navigator.canShare({ files })` が使える（iPhone Safari / Android Chrome）: 画像と文面を共有
3. それ以外（PC、Claude Artifact）: `#shareSheet` に画像を出し「長押しで保存」。「文面をコピー」はクリップボード → だめなら選択済みの欄
