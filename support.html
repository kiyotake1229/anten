暗転とは

触ると動ける。でも見えない。 白く光る点（熾火）を、上から落ちてくる黒い列の隙間に通し続けるゲームです。指で触れている間だけ熾火が動きます。けれど触れた瞬間にまぶたが閉じて、画面は真っ暗になります。指を離すと見えますが、動けません。

見るか、動くか。親指ひとつで選び続けてください。閉じたまま列を抜けると、得点が +2、+3、+4、+5 と増えていきます。

ブラウザで遊ぶ

遊び方の要点

基本

  • 画面のどこでもいいので触れると始まります。触れている間は熾火が動き、まぶたが閉じます。指を横に滑らせると熾火が横に動きます（指の縦の位置は関係ありません）
  • 離すとまぶたが開き、列が見えます。でも動けません
  • 列の隙間を抜けるたびに +1。前の列を抜ける前から閉じっぱなしで抜けると「暗列」になり、+2 → +3 → +4 → +5 と増えます。離すと連続は切れます
  • 黒い列に当たると終わり。タップ2回で次のラウンドです

列の種類

据え列と移り列
前の隙間とほぼ同じ位置の列（動かなくていい）と、動かないと抜けられない列。移り列は2本までしか続きません。3本目は必ず据え列です
忍び列（‹‹ ›› の印）
目を閉じている間だけ横に動きます。残像は琥珀色になります。印の向きと数（速さ）を見て、動く先を読んでください
鏡の列（「鏡」の印）
その列が次に来る間、閉じている間だけ左右の操作が逆になります。3本で1組です
選択列（隙間が2つ）
どちらも通れますが、片方は次の列の隙間から遠く、間に合わないことがあります。開いている間に次の列とつながる方を見ておいてください

覚えておくと楽になること

  • 残像: 閉じた瞬間に見えていた列が青白く残り、1秒ほどで消えます。閉じる前の一瞬で位置を目に焼き付けるのがコツです
  • 薄目: 離してすぐ（0.25秒以内）にもう一度触ると、熾火の近くだけ見える「薄目」になります。動けますが、暗列にはなりません
  • 閉眼リング: 閉じている間、熾火のまわりを細い円弧が1秒で1周します。暗闇の中の時間の目安です
  • 音: 列を抜けるたびに音が鳴り、暗列は隙間の位置に合わせて左右から聞こえます。忍び列が動くと擦れる音がします。耳でも位置が分かります

今日の暗転

その日の日付で決まる同じ配置に、1日3回だけ挑めます。2回目からは、その日のベストの軌跡が「ベスト」と書かれた輪で一緒に走ります。3回使い切ると記録を共有できます。

段位と熾火の色

段位（自己ベスト）見習い 0〜 / 手探り 20〜 / 夜目 50〜 / 暗中 100〜 / 心眼 200〜 / 無明 400〜
熾火の色（累計の列数）白 → 蒼（100列）→ 金（400）→ 紅（1,200）→ 虹（3,000）

よくある質問

画面が真っ暗になるのは故障ですか？
いいえ。触れている間は「まぶたが閉じている」状態で、これがこのゲームの決まりです。指を離すと見えます
音が鳴りません
タイトル画面のスピーカーのボタンか、設定の「音」を確かめてください。iPhone では本体の消音スイッチが入っていると鳴りません。音が無くても遊べるようにできています
振動しません
ブラウザ版の振動は Android だけです。iPhone はアプリ版で振動します。設定の「振動」で切り替えられます
指の動きに対して熾火の動きが大きい（小さい）
設定の「感度」で 低 / 標準 / 高 を選べます
記録はどこに保存されますか？
この端末の中だけです（ブラウザの localStorage、アプリ版はアプリの保存領域）。ブラウザのデータを消すと記録も消えます。別の端末には引き継げません
記録を消したい
設定の「データを消す」を2回押してください。ベスト・累計・設定がすべて消えます
画面の端で指が外れて「指が外れた」と出ます
画面の下端や左右の端ぎりぎりはスマホの操作（ホームに戻る等）に取られることがあります。少し内側で触れてください
理不尽な配置はありますか？
ありません。移り列は2本までで3本目は必ず据え列、隙間は必ず通れる幅、忍び列の動く先も必ず届く範囲に収めています。プログラムが自動で何千列も走って確かめています

お知らせについて（アプリ版）

アプリ版では、設定で「朝のお知らせ」を ON にすると、毎朝8時に「今日の暗転が新しくなった」と通知します。端末の中で予約する通知で、サーバーからは送りません。OFF にすると予約を取り消します。

プライバシーポリシー

暗転（以下「本アプリ」）は、ltv.work（以下「提供者」）が提供します。本アプリの個人情報の取り扱いは次のとおりです。

1. 集める情報

本アプリは、氏名・メールアドレス・位置情報・端末の識別子などの個人情報を一切集めません。アカウントの登録もありません。

2. 端末の中に保存する情報

遊んだ記録（ベスト・累計の列数・今日の暗転の記録と軌跡・設定・ヒントの表示回数）を、端末の中（ブラウザの localStorage、アプリ版はアプリの保存領域）にだけ保存します。これらは端末の外には出ません。設定の「データを消す」でいつでも消せます。

3. 通信

本アプリはサーバーと通信しません。広告・アクセス解析・トラッキングの仕組みは入っていません。「共有」を使ったときだけ、あなたが選んだアプリに記録の文面を渡します（提供者には送られません）。

4. 第三者への提供

集めていないため、第三者に提供することもありません。

5. お子さまの利用

年齢を問わず利用できます。個人情報を集めないため、お子さまの情報も集めません。

6. このポリシーの変更

変更するときは、このページで知らせます。

7. お問い合わせ

このポリシーについてのご質問は、下のお問い合わせからどうぞ。
